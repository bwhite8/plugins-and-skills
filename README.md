# plugins-and-skills

A collection of Claude Code plugins and skills.

## Agents

### [ai-transformation-advisor](./agents/ai-transformation-advisor/)

Advisor and content copywriter for AI enterprise strategy and training.

### [game-dev-architect](./agents/game-dev-architect.md)

Senior game developer and architect with 20+ years of experience. Helps with game mechanics, engine architecture, performance optimization, progression systems, and balancing — from indie projects to AAA-scale systems.

### [neon-db](./agents/neon-db/)

Database query assistant.  Leverages Neon MCP server to query a specific Neon Project ID, no project searching needed.

## Plugins

### [phased-workflow](./plugins/phased-workflow/)

A structured development workflow codified into four slash commands: brainstorm, plan, implement, and validate. Designed to keep complex features manageable across context windows by enforcing self-contained, sequentially implemented phases.

## Skills

### [mckinsey-writer](./skills/mckinsey-writer/)

Draft copy in first-person, in the style of a McKinsey consultant.
