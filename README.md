# plugins-and-skills

A collection of Claude Code plugins and skills.

## Plugins

### [phased-workflow](./plugins/phased-workflow/)

A structured development workflow codified into slash commands: brainstorm, plan, implement (or run the whole plan end-to-end), and validate. Designed to keep complex features manageable across context windows by enforcing self-contained, sequentially implemented phases.

## Skills

### [mckinsey-writer](./skills/mckinsey-writer/)

Draft copy in first-person, in the style of a McKinsey consultant.

### [writing](./skills/writing/)

Writes prose in a clear, substantive style inspired by Ethan Mollick and Andrew Ng — evidence-led, essayistic, no AI-tell vocabulary.
